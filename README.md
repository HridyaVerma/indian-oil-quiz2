# Indian Oil Concave Quiz App

## 🚀 Overview
This project was developed as part of the **Indian Oil Concave Quiz**, where we built a real-time quiz platform to efficiently manage large-scale participation.

The system enables **200+ users** to participate simultaneously in a **"Fastest Finger First"** round, with real-time response tracking and a live leaderboard for the quiz master.

---

## 🎯 Problem Statement
Managing quiz competitions with a large number of participants is challenging due to:
- Delays in collecting responses  
- Difficulty in identifying the fastest correct answer  
- Lack of real-time leaderboard updates  

The goal was to design a **scalable and responsive quiz system** for fair and efficient evaluation.

---

## 💡 Solution
We developed a **real-time quiz application** that:
- Captures responses from multiple users simultaneously  
- Determines the fastest correct response  
- Updates rankings dynamically  
- Displays a live leaderboard for the quiz master  

---

## ⚙️ Key Features
- ⚡ Fastest Finger First response system  
- 👥 Supports 200+ concurrent users  
- 📊 Real-time leaderboard  
- ⏱️ Accurate response time tracking  
- 📄 Lightweight database using Google Sheets
